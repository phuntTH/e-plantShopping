# 🌿 Paradise Nursery - Shopping Cart Application

## Overview

Paradise Nursery is a React-based e-commerce web application that allows users to browse a collection of plants, view product information, and manage a shopping cart. The application demonstrates the use of React components, state management, and dynamic user interactions to create a simple and responsive online shopping experience.

## Features

* Browse a collection of indoor and outdoor plants.
* View product images, names, descriptions, and prices.
* Add plants to the shopping cart.
* Increase or decrease the quantity of each item.
* Remove items from the shopping cart.
* Automatically calculate the total number of items.
* Automatically calculate the total purchase cost.
* Responsive and user-friendly interface.
* Navigation between the product listing and shopping cart pages.

## Installation

1. Clone the repository.

```bash
git clone https://github.com/your-username/Paradise-Nursery.git
```

2. Navigate to the project directory.

```bash
cd Paradise-Nursery
```

3. Install the required dependencies.

```bash
npm install
```

4. Start the development server.

```bash
npm start
```

The application will run at:

```text
http://localhost:3000
```

## How to Use

1. Open the application in your browser.
2. Browse the available plants.
3. Click **Add to Cart** to add products.
4. Use the shopping cart page to:

   * Increase quantity
   * Decrease quantity
   * Remove items
5. Review the automatically updated total price and total number of items.
